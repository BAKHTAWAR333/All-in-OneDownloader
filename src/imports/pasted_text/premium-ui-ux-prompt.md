Premium Human-Crafted UI/UX & Animation Prompt

Redesign and fully optimize this website from the ground up. The goal is to make it feel human-designed, premium, original, highly intentional, and creatively art-directed — absolutely not like an AI-generated website or generic “AI vibe coding” template.

Think like a world-class creative team of 40,000+ elite UI/UX designers, creative directors, motion designers, interaction designers, and digital art directors working together on one flagship experience.

1. Rebuild the Visual Identity

Do not simply polish the existing UI. Reimagine it.

Create a strong visual identity with:

- Sophisticated typography hierarchy
- Exceptional spacing and composition
- Editorial-style layouts
- Unexpected but purposeful visual elements
- Strong contrast between sections
- Premium grids and asymmetric compositions
- Custom-designed cards instead of generic template cards
- Subtle imperfections and human creative decisions
- Rich visual storytelling
- High-quality image treatment
- A consistent design language throughout the entire website

Avoid anything that immediately signals:

«“This was generated by AI.”»

No generic gradients, excessive glassmorphism, random floating blobs, repetitive rounded cards, overused glow effects, predictable SaaS layouts, or unnecessary sections.

2. Make My Image a Major Creative Element

Use my provided image as an important part of the visual identity.

Do not just place it inside a normal profile card.

Turn it into an art-directed visual experience.

Experiment with:

- Large editorial portrait treatment
- Cropped image compositions
- Layered image + typography
- Image reveal animations
- Mask transitions
- Parallax movement
- Interactive cursor effects
- Subtle distortion
- Grain/noise overlays
- Light/shadow interaction
- Image transitions between sections

The image should feel integrated into the story of the website rather than simply “inserted.”

3. Create a Strong First Impression

The hero section needs to immediately communicate:

Who I am → What I create → Why it matters.

Use powerful, concise writing.

Do not use generic copy such as:

«“Welcome to my portfolio.”»

Instead, create an editorial-quality headline with personality and confidence.

Typography should become part of the animation.

For example:

- Words entering individually
- Character-level reveals
- Masked text transitions
- Large typography moving with scroll
- Variable font weight changes
- Text splitting and recomposition
- Strategic oversized typography

Every animation should support the message.

4. Build a Cinematic Scroll Experience

The website should feel like a digital experience, not a collection of sections.

Create a carefully choreographed scroll journey.

Use professional animation libraries where appropriate, such as:

- GSAP
- ScrollTrigger
- Lenis
- Framer Motion / Motion
- Three.js where genuinely useful
- WebGL only when it adds meaningful value

Do not use every library just because it is available.

Use the right tool for the right interaction.

5. Premium Animation Direction

Create animations that feel expensive and intentional.

Include:

Page entrance

- Smooth initial loading sequence
- Logo/identity reveal
- Typography entrance
- Image reveal
- Elegant transition into the main experience

Scroll animations

- Smooth section transitions
- Horizontal movement where appropriate
- Image scaling
- Text transformations
- Parallax depth
- Mask reveals
- Sticky storytelling
- Layered compositions

Micro-interactions

- Sophisticated hover states
- Magnetic buttons
- Custom cursor interactions
- Image hover transformations
- Navigation transitions
- Smooth link feedback
- Button physics
- Subtle text movement

Page transitions

Create seamless transitions between pages instead of instantly replacing content.

The experience should feel like one continuous film.

6. Creative Section Design

Do not create the standard:

Hero → About → Services → Skills → Projects → Contact

Instead, make every section feel like a new visual chapter.

Possible chapters:

01 — INTRODUCTION

A cinematic introduction with my image and statement.

02 — THE PERSON

A creative presentation of who I am.

03 — THE CRAFT

Show my skills through visual storytelling instead of boring progress bars.

04 — SELECTED WORK

Turn projects into immersive case-study experiences.

05 — PROCESS

Show how ideas transform into finished digital experiences.

06 — EXPERIENCE

Present experience through an editorial timeline or unconventional composition.

07 — FINAL STATEMENT

A powerful closing visual moment.

08 — CONTACT

Make contacting me feel like the final scene rather than a basic form.

These are only conceptual directions. Improve them if a better structure exists.

7. Project Showcase

Projects should feel like case studies, not generic portfolio cards.

Create large visual project presentations with:

- Large artwork
- Project title
- Short creative description
- Technology
- Role
- Results where available
- Interactive preview
- Hover animation
- Scroll-based image movement
- Smooth project transition

Make each project feel like its own mini experience.

8. Typography

Typography is one of the main design elements.

Use a sophisticated font pairing and carefully control:

- Font sizes
- Line height
- Letter spacing
- Weight
- Width
- Text density
- Responsive typography

Create moments with massive editorial typography, but balance them with quiet minimal compositions.

Do not make everything huge.

Use contrast.

9. Navigation

Create an elegant navigation system.

It should be:

- Minimal
- Highly usable
- Responsive
- Animated
- Visually distinctive

Consider a navigation that transforms while scrolling.

For example:

Initial state → expanded identity

Scrolling → compact floating navigation

Menu opening → cinematic full-screen transition

Keep usability more important than visual tricks.

10. Human Design Rules

This is extremely important.

The website must not feel AI-generated.

Avoid:

- Generic AI portfolio layouts
- Excessive gradients
- Excessive rounded rectangles
- Random 3D objects
- Fake statistics
- Meaningless animations
- Repeated component patterns
- Generic “creative developer” copy
- Overused neon colors
- Too much glassmorphism
- Excessive shadows
- Unnecessary floating elements

Instead:

Make intentional design decisions.

Every element should have a reason to exist.

Create visual hierarchy through composition rather than decoration.

11. Premium Interaction Quality

The website should feel exceptional on:

- Desktop
- Tablet
- Mobile

Animations must remain smooth and performant.

Respect:

- Reduced-motion preferences
- Accessibility
- Keyboard navigation
- Touch interactions
- Mobile performance
- Image optimization
- Lazy loading

Do not sacrifice usability for animation.

12. Writing & Content

Rewrite weak text.

Make the writing:

- Short
- Confident
- Human
- Specific
- Memorable
- Professional

Remove unnecessary filler.

Do not write like an AI.

Avoid phrases such as:

«“I am passionate about creating innovative digital experiences.”»

Use language with personality and specificity instead.

13. Final Creative Direction

The final website should feel like a combination of:

Premium portfolio + digital art direction + editorial design + cinematic motion + modern interaction design.

It should look like something created by a top-tier independent creative studio, not a template marketplace and not an AI website generator.

The viewer should immediately think:

«“Someone extremely talented designed this.”»

Not:

«“This looks AI-generated.”»

Push the design significantly beyond the existing version.

Do not merely improve the current UI. Re-art-direct the entire experience.

Make the final result cleaner, more expressive, more memorable, more premium, more human, and dramatically better animated while maintaining excellent usability and performance.
